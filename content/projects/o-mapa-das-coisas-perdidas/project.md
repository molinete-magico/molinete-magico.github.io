# O Mapa das Coisas Perdidas

Lina trabalha redesenhando mapas de uma cidade que muda um pouco a cada estação. Um dia, encontra no arquivo uma rua que ninguém lembra — nem mesmo as pessoas que moram ao redor dela.

Este projeto demonstra uma história publicada por partes. O prólogo funciona como a entrada da leitura; cada capítulo tem seu próprio arquivo Markdown e pode ser publicado sem liberar os capítulos seguintes.

## Como explorar

- Abra a leitura para começar pelo prólogo.
- Escolha um capítulo no sumário à esquerda.
- Consulte os complementos para encontrar notas e detalhes que não fazem parte da narrativa principal.

Os capítulos futuros podem permanecer no repositório com `published: false` até estarem prontos.
